# THREE.JS

Three.js should load dynamically.

Do not block first paint.

Use a lightweight fallback.

Desktop:

full experience.

Tablet:

reduced experience.

Mobile:

2D fallback where appropriate.

---

# VIDEO

Never load every video immediately.

Use poster images.

Lazy load.

Use:

preload="metadata"

Muted autoplay previews only when appropriate.

Mobile:

do not autoplay large videos unnecessarily.

# MOBILE PRINCIPLE

Never simply scale desktop down.

Recompose layouts.

Reduce:

performance

---

# FALLBACK

If:

WebGL unavailable
device is low-power
reduced motion enabled

use:

2D image experience.

The website must remain beautiful.

---

# ERROR HANDLING

Missing image:

show elegant fallback.

Missing video:

show poster image.

WebGL error:

automatically fall back to 2D.

No network:

previously cached essential shell should still render.
